Cannot open the page after scanning?

Make sure both devices use the same Wi-Fi network and the server is still running. If Windows prompts you, allow Python to communicate on your private network. Public Wi-Fi networks may block device-to-device connections; try connecting your computer to your phone hotspot and re-enabling the connection.

If the server was started using the older local-only command, stop it and relaunch it using the desktop start script.
